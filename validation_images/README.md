# 固定真实验证集

这里存放经过人工确认、用于模型回归检查的真实小地图样本。目录会提交到 Git，`preprocess.py` 每次重建数据集时都会校验并自动复制到 `dataset/val`。

目录格式：

```text
validation_images/
└── <class_name>/
    └── <sample_name>.png
```

约束：

- 目录名必须是本次预处理实际生成的类别名。
- 图片必须已经按线上推理流程裁剪并遮罩为 `128×128`。
- 每张图只保留一个明确标签；同一张图不得同时放入 `error_images`。
- 文件名应稳定、可追溯，避免使用 `fixed_` 前缀；该前缀由预处理脚本写入生成数据集时自动添加。
- 同一段连续录像只保留能代表不同错误吸附方向的少量帧，避免重复帧左右综合评价。

训练时，固定验证集会独立计算交叉熵，其平均损失和最差样本损失会与生成验证集共同决定 `best.pt` 和 early-stop；它不会进入训练集。
